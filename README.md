# Шаг за шагом

Учебная информационная система магазина обуви.

Проект предназначен для работы с каталогом товаров, остатками и заказами.
Система предусматривает различные уровни доступа для гостя, клиента, менеджера и администратора.

## Стек технологий
- MySQL и MySQL Workbench — проектирование базы данных и работа с SQL;
- C# и Visual Studio 2022 — планируемая реализация клиентского приложения.

## Структура проекта

- `docs/` — проектная документация и диаграммы;
- `db/` — модель, SQL-скрипты и данные базы;
- `src/` — исходный код клиентского приложения на C# (будет добавлен на следующих этапах).

На текущем этапе в репозитории представлены материалы проектирования и подготовки базы данных. Клиентское приложение на C# ещё не добавлено; его реализация предусмотрена на следующих этапах учебного проекта.
